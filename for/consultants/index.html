Who it's for

Consultants who run GIS for small organizations

Many small organizations get their GIS from an engineering firm, a planning consultancy, or a one-person shop that already knows PostGIS. Those firms assemble an open-source stack by hand for each client, and the integration is where their hours go. Talus is that stack, already integrated, installed per client in an afternoon, with no license line to pass through.

What it does for you

One install per client, no per-client license. Talus Community is free under the AGPL for every client you deploy it for: the complete portal, hosted layers, web maps, interop doors, backups, and the invariant suite. Install it on the client's host or on a server you run for them; it is the same installer and the same product either way, and moving a client from your server to theirs later is a restore, not a migration.

Your tools already connect. One connection file puts a client's whole catalog into ArcGIS Pro or QGIS. The documented /api/v1 with scoped service-account tokens lets you script loads and checks from your own environment. Read-only copies of the client's work-order, permit, or billing tables refresh nightly without an ETL project.

Fewer midnight calls. Upgrades are versioned releases you pull, each rehearsed on a test server, with every image pinned by digest. Backups go to a destination you name, encrypted to keys you hold once you add them, and the restore drill is one script whose last result shows on the admin pages. Nothing phones home, and the short list of outbound connections is in the security overview, each one an administrator's to switch off.

Talus+ for the firm, or for the client. Support from the people who build Talus, plus dashboards, scheduled reports, story maps, and Talus Field, on one flat, public price per deployment. Quote it through, or carry it yourself; either way the price is the published price.

What you need

What the AGPL asks of you, plainly. Run Talus unmodified for a client and it asks nothing: using the software, even to serve a client over a network, creates no obligation to publish anything. Modify it and serve your modified version to others, and the people who use it are entitled to your changes. If a client's procurement bans the AGPL outright, a commercial license for the identical code is available from Talus GIS LLC.

The name. Say that your service runs on Talus GIS; that is true and welcome. The name and mark belong to Talus GIS LLC, so your service is yours by your name, built on Talus.

A host per client. A VM on the client's server, a Linux host with Docker, or a cloud server you operate; four vCPUs and 8 GB per deployment is comfortable for a small organization. Each client is its own install with its own data and its own backups.

What it deliberately does not do

There is no reseller program, partner tier, or white-label edition today. If you want one, write to us and say what it would need to be; the answer will be a conversation, not a brochure. Talus is not multi-tenant. One install serves one organization; serving several clients from one portal is deliberately not supported, because the authorization model, the backups, and the audit trail are per organization. No feature grid against ArcGIS: Talus wins on operational simplicity, cost of ownership, and trust, and loses on the exotic 20% on purpose. Field Maps and Survey123 cannot be pointed at Talus; QField and Talus Field are the field path.

A firm that deploys Talus for its clients is also the "someone answerable" those clients want locally. Talus GIS LLC stays answerable for the product.
